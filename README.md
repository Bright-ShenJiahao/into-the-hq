# 深入日军总部 Into the HQ

杀戮尖塔式卡牌肉鸽（网页版，纯原生 JS）。当前是**最小可玩版**：只有韩松一个角色、第一章「林海雪原」，美术全部是色块占位。

## 文件
- `index.html`：页面和样式（横屏 1280×720 舞台，手机自动放大按钮和字）
- `src/data.js`：武器、25 张卡、8 种敌人、遭遇、地图事件
- `src/engine.js`：战斗规则（纯逻辑，不碰页面；以后机器人模拟直接用这一份）
- `src/game.js`：界面和流程（标题、地图、战斗、战利品、密营、事件、结局、调试面板）

## 试玩
- preview 分支用 raw.githack 打开，链接里带完整提交编号，加 `?debug` 显示调试按钮。
- 只有 main 分支会在 Netlify 上部署。
