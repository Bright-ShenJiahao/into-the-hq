# 人物拼图与过场（2026-11-21 定稿）

## 规则
- 小分队六人（五个可玩角色 + 老沈）加金永哲，每人一张拼图，5 块，散在三章的事件里，最后一块在真结局。
- 拼到的块**跨局保存**（图鉴「人物」页显示 x/5，没拿到的写「？？？ · 第几章」）。
- 不管选谁当主角，队伍里六个人都在，所以谁的拼图块都能碰到；每人留 1 块「只有用他打才会碰到」。
- 拼图块用**过场**呈现（日式文字冒险版面：全屏场景 + 左右立绘 + 名字牌 + 对白框），不用普通事件面板。放完：体温 +2、生命 +5。
- 出现方式：事件格 50% 换成一块没拿过的拼图（都拿过了 20%）；「运输清单」在第一次截下档案箱后回到地图时放；韩松 × 村濑替换首领开战对白。
- 拼齐一个人：结算页「他们」里有这个人的结局段落；全拼齐 + 真结局：尾声（1945 年以后各自去了哪里）。（待做）

## 关系网（全部虚构；不写神剧，只写人和人之间欠着、瞒着、对不上）
- **老沈 × 沈知秋的父亲**：中学教员因读书会被宪兵抓走，到死没供出给读书会递书的人——就是老沈。老沈欠他一条命，所以把他女儿带出来，她随了老沈的姓。老沈最后一块，真结局揭开。
- **陈默的父亲**：伪满经济部管物资调运的中层官员，在「交接副本」上签了字，没问「特殊物资」是什么。
- **真结局**：「特别移送」名单的编号里有沈知秋认得的名字；签字的人里有陈默的父亲。一个是被送走的人的女儿，一个是签字的人的儿子。只写她看到名单那一刻。
- **田守义 × 邢二嫂**：第二章豆腐坊的邢二嫂就是他的闺女田秀兰。他认出来了，没敢认；后来她被抓，一个字都没说。（第二章事件要跟着改）
- **韩松 × 村濑**：三道沟那次「归屯并户」烧了他家，带队的是村濑。
- **金永哲 × 哥哥**：哥哥在日伪的朝鲜人部队（「间岛特设队」，写进去前先查证）。第一章的朝鲜族俘虏念着弟弟「永哲」。
- **赵铁山 × 老沈**：九一八那夜接到「不抵抗」命令一枪没放；那一夜老沈在哪，他没问出口。最后一块在真结局：这回他没退。
