# 第三章「地下」怪物设计 v1

2026-11-21。规则已经写进代码（src/content/ch3.js），这里定外观、行为表现和出图清单。美术还没出：人类敌人借第一章的图，墓里的东西用暗色块顶着。

---

## 〇、总原则

1. **怪物绝不来自受害者。** 墓里的东西都和这座辽金古墓有关，比战争老得多；死在战争里的人不变成任何东西。
2. **不说破。** 它们到底是什么，游戏里从头到尾不解释。图鉴写「古墓里的东西。它到底是什么，没有人说得清」。
3. **不靠血腥。** 恐怖来自轮廓不对、动作不对、数量不对：太长的手臂、没有脸的脸、学人学得差一点点。没有伤口、内脏、尸体。
4. **人类敌人写实**：日军的军服、装备照 1945 年夏季（夏衣、略帽或钢盔），不加任何怪异的东西。
5. **画风**：沿用现有的半写实厚涂。墓里的东西用低饱和、近乎黑白，只留一点冷色（青灰、铜绿）；它们在画面里应该「看不太清」。

## 二、墓里的东西

### 1. 影子
- **外观**：一团站着的黑，大约一人高，边缘像墨滴进水里一样往外洇。没有五官。它离你越近，边缘越清楚；你越想看清，它越糊。
- **动作**：待机时轻轻起伏，像在呼吸，可是节奏和人不一样；攻击时一下子「贴过来」，中间没有过程；受击时散开再聚拢（对应「散开了」躲掉一下）；倒下时像烟一样沉到地上。
- **规则**：意图全部看不见（沈知秋看得见）；每回合有一半机会躲掉一下；「冷」让你虚弱、理智 -1。

### 2. 回声
- **外观**：一个模糊的人形轮廓，姿势是你上一回合出手的姿势——抬手、拔刀、举枪，可是比你慢半拍、关节弯的方向差一点点。看不清脸，也看不清是谁。
- **动作**：待机时偏着头「在听」；攻击时做出你的动作；受击时像水面被打碎又合拢。
- **规则**：「在听」加格挡；「学你」打出你上一下打出的伤害。

### 3. 守墓的东西
- **外观**：远看像墓门口一座长满青苔的石兽，蹲着；近看石头的缝里有东西在慢慢动。比人高一倍，很重，很慢。
- **动作**：待机几乎不动，偶尔「翻身」时碎石往下掉；攻击是整个压下来；受击时石皮崩下一块，里面是黑的；倒下时重新变回一堆石头。
- **规则**：翻身（厚格挡，理智 -1）/ 压下来（大伤害）交替。

### 4. 戴金属面具的东西（精英）
- **外观**：一张契丹金属面具（鎏金铜面具，眉眼细长，面容平静）浮在一人高的位置，下面撑着一件朽烂的锦袍——**袍子里是空的**。它不是墓主人，是「捡起面具戴上的东西」。袖口里偶尔伸出一只过长的、像树枝一样的手。
- **动作**：待机时面具缓缓转向你，永远正对着镜头；「伸手」时袖子里的手伸得很长，从你的牌里拿走一张；「面具在看你」时画面微微变暗。
- **规则**：拿走你一张牌两回合 / 抓两下 / 盯着你（理智 -1、易伤）。
- **史实**：辽代契丹贵族有金属面具覆面的葬俗，图鉴注明；面具的样子参考出土文物的风格，不照搬某一件。

## 三、首领

### 随军神官·鹫尾（虚构）
- **外观**：五十来岁，瘦，颧骨高，眼窝深。日军军服外面罩一件白色狩衣，戴黑色立乌帽子；右手持御币（白纸垂），左手握一柄短神刀。狩衣下摆沾着土和铁屑。眼神是平静的，平静得不对。
- **立绘**：半身，站在墓室正中，身后地上钉着三颗镇龙钉，钉子周围的土是黑的。光从下往上打。
- **动作帧**：待机（摇御币）、攻击（神刀劈下）、钉钉（双手举钉往下砸）、受击、倒下。
- **台词**（日语标注）：「你们也听见了吧？地底下的声音。」「这片土地的龙脉，由我来钉死。帝国撤走了，钉子会留下来。」「……所以他们的刀，才配做成钉子。」
- **史实边界**：阴阳寮 1870 年已废，他是自称；「钉龙脉」是民间说法，无可靠史料；批判的是被当作侵略工具的国家神道和军国主义。

### 镇龙钉
- **外观**：手腕粗、半人高的铁钉，钉帽刻着符，缠着褪色的纸垂。铁的颜色发暗，隐约看得出是很多把刀熔在一起——刀纹没熔干净。
- **规则**：每回合给神官 6 格挡；拿「断刀柄」打钉子伤害翻倍。

### 它
- **外观**：**永远不画全。** 画面上方是一片比黑暗更黑的东西，只看得见边缘——像一座山的轮廓，又像一只巨大的、正在睁开的眼睑。萨满的鼓每响一下，它就往后缩一点。
- **表现**：没有血条，显示「打不动 · 只能用仪式封回去」。它出现时整个战斗画面再暗一层；仪式进行到第三步时，画面从下往上慢慢亮起来。
- **规则**：压下来（理智 -1）/ 低语（两张「恐惧」混进牌堆）/ 伸过来（两下）。剩下几颗钉，它的力量就加几分。

### 萨满老人（不是敌人）
- **外观**：七十来岁的满族老人，瘦，背微驼，穿旧的蓝布长袍，腰上系一圈铜腰铃，手里是蒙兽皮的单面神鼓。脸上皱纹很深，眼睛很亮。**写实、庄重，不画成跳大神的滑稽样子。**
- **立绘**：半身，坐在墓道口，鼓放在膝上，背后是黑的。
- **史实**：「萨满」原意是「知道、智慧」；神鼓、腰铃、神刀是满族萨满的真实器物；背灯祭在夜里不点灯进行。写之前再核一遍学术资料。
